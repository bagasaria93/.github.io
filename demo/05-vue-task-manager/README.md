# TugasKu - Vue Task Manager

Demo project by Bagas Aria Sativa - Portfolio Demo
https://bagasaria93.github.io

---

## Deskripsi

TugasKu adalah aplikasi manajemen tugas personal berbasis Vue 3 Composition API. Dirancang dengan aesthetic soft paper/notebook yang elegan dengan aksen teal. Semua data tersimpan di localStorage sehingga tidak hilang saat refresh.

---

## Fitur

- Vue 3 Composition API via CDN
- CRUD task lengkap dengan animasi transisi masuk/keluar
- Drag and drop reorder task
- Kategori: Pekerjaan, Personal, Belajar
- Prioritas: Tinggi, Sedang, Rendah dengan color coding dan indikator
- Filter sidebar: by status, by kategori, by prioritas
- Sort: Terbaru, Tenggat, Prioritas, Kategori
- Search realtime by judul dan deskripsi
- Due date dengan overdue indicator merah otomatis
- Progress bar animated persentase completion
- Dark mode dengan toggle dan localStorage persistence
- Empty state per kondisi filter
- Konfirmasi modal sebelum hapus task
- Responsive layout dengan mobile sidebar
- Sample tasks preloaded saat pertama kali dibuka
