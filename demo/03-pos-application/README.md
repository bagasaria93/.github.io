# Demo 03 - KasirKu: POS Application

Aplikasi kasir untuk Warung Kopi Nusantara. Konteks menu kopi lokal Indonesia, harga Rupiah.

---

## Tech Stack

- HTML5, CSS3
- Tailwind CSS (via CDN)
- jQuery 3.7.1 (via CDN)
- Vanilla JavaScript
- localStorage

## Fitur

- jQuery DOM manipulation
- Product grid dengan kategori filter animated
- Search produk realtime dengan highlight teks
- Cart dengan add, remove, quantity stepper
- Kalkulasi: subtotal, diskon kode kupon, pajak 10%, total
- Kode kupon valid: KOPI10, DISKON5K, HEMAT15
- Stock indicator per produk, stok berkurang saat checkout
- Receipt generator tampilan print-friendly
- Print receipt via window.print()
- Transaction history via localStorage
- Tab riwayat transaksi
- Keyboard shortcut: Enter untuk checkout, Escape untuk tutup modal
- Visual flash feedback saat tambah produk ke cart
- Konfirmasi modal untuk aksi destruktif

## Cara Menjalankan

Buka file `index.html` langsung di browser. Tidak memerlukan server atau dependensi tambahan.
