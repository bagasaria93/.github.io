# Company Profile 06 - Karsa Bangun: Kontraktor Bangun dan Renovasi Rumah

Landing page company profile untuk kontraktor bangun dan renovasi fiktif, meliputi bangun baru, renovasi rumah, interior dan finishing, hingga konsultasi dan RAB.

**Tagline:** Bangun dan Renovasi Rumah dengan Perencanaan yang Jelas, Tanpa Kejutan Biaya.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Archivo, Source Sans 3)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna graphite dan steel blue di atas latar stone hangat, berbeda dari demo lain agar terasa seperti identitas kontraktor yang kokoh dan profesional
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan baris kredensial angka yang animasi saat scroll dan kartu highlight melayang
- Slider interaktif Sebelum dan Sesudah dengan drag mouse dan touch untuk membandingkan hasil renovasi
- Empat Layanan Utama dalam kartu dengan ikon custom
- Timeline Proses Kerja horizontal dengan empat tahap bernomor
- Galeri Portofolio dengan filter kategori Renovasi Rumah, Bangun Baru, dan Interior
- Testimoni klien dalam grid kartu dengan tag jenis proyek
- Form Minta Penawaran Gratis dengan validasi inline per field (tanpa alert browser)
- FAQ accordion dengan ikon plus yang berputar saat item aktif
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
