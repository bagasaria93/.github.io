# Company Profile 05 - Klinik Nirmala: Klinik Keluarga dan Kesehatan Umum

Landing page company profile untuk klinik keluarga fiktif, meliputi Poli Umum, Poli Gigi, Poli Anak, dan Poli Kandungan.

**Tagline:** Kesehatan Keluarga Anda, Kami yang Jaga.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Outfit, Karla)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna biru dan violet di atas latar putih kebiruan lembut, berbeda dari demo lain agar terasa seperti aplikasi klinik modern dan terpercaya
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan foto dalam kartu membulat, latar pola titik, dan widget status Klinik Buka Sekarang yang membaca jam saat ini secara real time
- Kartu statistik dengan ikon dan animated counter scroll triggered
- Empat Poli Utama dalam kartu dengan header ilustrasi ikon berwarna gradasi, bukan foto
- Jadwal Dokter dalam format tabel jadwal praktik, lengkap dengan foto, spesialisasi, hari, dan jam praktik
- Layanan Unggulan dalam horizontal scroll snap carousel tanpa tombol navigasi
- Galeri fasilitas dengan foto dan keterangan di bawah foto
- Testimoni pasien dalam tampilan spotlight tunggal yang berganti otomatis dengan indikator titik
- FAQ dengan navigasi sidebar dan panel jawaban di sisi kanan
- Form janji temu dengan validasi inline (tanpa alert browser)
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
