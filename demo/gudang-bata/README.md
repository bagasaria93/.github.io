# Company Profile 12 - Gudang Bata: Toko Bahan Bangunan

Landing page company profile untuk toko bahan bangunan fiktif yang menjual semen, besi, cat, pipa, keramik, hingga perkakas untuk kebutuhan rumah tangga maupun kontraktor.

**Tagline:** Semua Ada. Semua Siap.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Stardos Stencil, Barlow Condensed, Barlow, Caveat)

## Konsep Desain

Desain mengangkat identitas visual gudang dan toko material bangunan, dibedakan dari demo company profile lain lewat palet warna, tipografi, dan pola layout yang berbeda:

- Palet warna kuning safety (hazard yellow), charcoal gelap, dan abu krem seperti beton, khas gudang dan toko material
- Tipografi stencil (Stardos Stencil) untuk judul besar seperti stensil semprot di kardus/gudang, dipadu Barlow Condensed untuk label dan Barlow untuk isi
- Aksen garis diagonal hazard stripe (kuning-hitam) di sisi hero, bukan motif dekoratif generik
- Header solid dan sticky dengan navigasi kategori bergaya tab, berbeda dari navbar transparan pada demo lain
- Menu mobile berupa panel dropdown di bawah header, bukan overlay penuh layar
- Kategori produk disajikan sebagai bento grid foto asimetris, bukan grid kartu seragam atau scroll horizontal
- Papan Harga bergaya papan tulis toko dengan angka ditulis gaya tulisan tangan (font Caveat), lengkap dengan disclaimer harga bisa berubah
- Bagian Kenapa Kami memakai foto rak toko asli sebagai bukti fasilitas, bukan hanya foto barang jadi
- Testimoni memakai rating bintang, sesuai konteks bisnis retail

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Utility bar jam operasional, telepon, dan info area pengiriman
- Header sticky dengan navigasi kategori dan tombol Order WhatsApp
- Menu mobile dropdown dengan animasi buka tutup
- Hero dengan headline besar, aksen hazard stripe, dan panel angka statistik bergaya readout
- Kategori Produk dalam bento grid enam kategori dengan foto asli gudang dan toko material
- Papan Harga estimasi delapan item populer dengan disclaimer harga pasar
- Layanan Antar Barang, Potong Custom, Konsultasi Gratis, dan Termin Kontraktor
- Bagian Kenapa Kami dengan foto rak toko dan checklist keunggulan
- Testimoni pelanggan dengan rating bintang
- FAQ accordion dengan ikon panah yang berputar saat item aktif
- Form Pesan Bahan Bangunan dengan validasi inline per field tanpa alert browser, termasuk pilihan metode diantar atau ambil di toko
- Info kontak alamat toko, telepon, email, dan jam operasional
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
