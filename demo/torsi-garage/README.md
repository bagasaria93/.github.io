# Company Profile 07 - Torsi Garage: Bengkel Servis Mobil dan Motor

Landing page company profile untuk bengkel servis mobil dan motor fiktif, meliputi servis berkala, ganti oli, spooring dan balancing, servis kelistrikan dan AC, hingga servis motor matic dan kopling.

**Tagline:** Servis Kendaraan yang Jujur, Cepat, dan Bergaransi.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Oswald, Mulish)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna asphalt black dan racing yellow di atas latar concrete gray, memberi kesan bengkel otomotif yang tegas dan mudah dipercaya
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan baris statistik angka yang animasi saat scroll dan kartu highlight garansi servis
- Toggle switch interaktif Mobil dan Motor pada bagian Harga Servis yang mengganti daftar harga secara dinamis
- Enam Layanan Utama dalam kartu dengan ikon custom dan penanda kategori Mobil, Motor, atau keduanya
- Galeri dengan filter kategori Semua, Mobil, dan Motor
- Testimoni pelanggan dalam grid kartu dengan rating bintang
- Form Booking Servis dengan validasi inline per field tanpa alert browser, mencakup nama, no HP atau WhatsApp, jenis kendaraan, jenis servis, tanggal servis, plat nomor, dan catatan tambahan
- FAQ accordion dengan ikon plus yang berputar saat item aktif
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
