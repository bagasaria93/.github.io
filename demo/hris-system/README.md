# HRIS PT Cakrawala Gemilang - Human Resource Information System

Sistem informasi SDM untuk PT Cakrawala Gemilang, mencakup manajemen karyawan, kehadiran, cuti, payroll, rekrutmen, kinerja, pelatihan, dan pengumuman dalam satu dashboard dengan kontrol akses berbasis peran.

## Tech Stack

- HTML5, CSS3
- Vanilla JavaScript (localStorage sebagai database demo)
- Lucide Icons
- Chart.js
- Plus Jakarta Sans - Google Fonts

## Fitur

- Login dengan kontrol akses berbasis peran (Super Admin, HR Manager, HR Staff, Karyawan)
- Dashboard dengan KPI, grafik kehadiran, distribusi karyawan, dan ringkasan status
- Manajemen Karyawan dengan CRUD data lengkap dan ekspor CSV
- Rekap Kehadiran dengan clock in/out, filter bulan dinamis, dan tambah data manual
- Manajemen Cuti dengan approval workflow dan saldo cuti yang otomatis terpotong saat disetujui
- Penggajian dengan slip gaji, cetak, dan konfigurasi tarif BPJS
- Rekrutmen dengan pipeline kandidat per tahap
- Manajemen Kinerja dengan penilaian KPI per periode
- Pelatihan & Pengembangan dengan pendaftaran dan tracking penyelesaian peserta
- Pengumuman dengan kategori, status publish/draft, dan pin
- Struktur Organisasi dengan bagan organisasi, departemen, dan jabatan
- Laporan & Analitik: headcount, kehadiran, penggajian, cuti, dan turnover
- Pengaturan profil perusahaan, kebijakan kerja, tarif BPJS, akun, dan sistem

## Cara Menjalankan

Buka file `index.html` langsung di browser untuk login. Tidak memerlukan server atau proses build tambahan untuk menjalankannya.
