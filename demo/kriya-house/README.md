# Company Profile 03 - Kriya House: Retail & Toko Kriya Lokal

Landing page company profile untuk toko retail fiktif yang mengkurasi produk kriya dan kerajinan tangan lokal, meliputi home decor, fashion aksesoris, self care, dan gift.

**Tagline:** Setiap Karya Punya Cerita untuk Dibawa Pulang.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Manrope)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna terang (cream, rose, ink, gold) berbeda dari demo lain agar terasa seperti butik retail
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan foto produk, badge kemasan, dan stats bar dengan animated counter scroll triggered
- Marquee berjalan menampilkan daftar kategori produk
- Grid kategori bergaya bento (asimetris) dengan overlay nama dan deskripsi
- Produk Unggulan, grid 6 produk dengan foto, kategori, deskripsi, dan harga
- Cerita Kami dengan tiga pilar nilai brand dan kutipan bergaya editorial
- Galeri suasana toko dengan horizontal scroll snap
- Testimoni pelanggan
- FAQ accordion dengan smooth expand dan collapse
- Form kontak dengan validasi inline (tanpa alert browser)
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
