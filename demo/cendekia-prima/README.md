# Company Profile 08 - Cendekia Prima: Bimbingan Belajar SD, SMP, SMA, dan UTBK

Landing page company profile untuk lembaga bimbingan belajar fiktif, meliputi program untuk jenjang SD, SMP, SMA, hingga persiapan UTBK.

**Tagline:** Belajar Jadi Terarah, Nilai dan Percaya Diri Ikut Naik.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Baloo 2, Nunito Sans)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna indigo dan coral di atas latar cream, memberi kesan bimbingan belajar yang ramah namun tetap kredibel
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan baris statistik angka yang animasi saat scroll dan kartu highlight try out rutin
- Tab pilihan jenjang SD, SMP, SMA, dan UTBK pada bagian Program dan Harga yang mengganti daftar program serta harga secara dinamis, tiap jenjang punya tiga pilihan program dengan satu program unggulan
- Empat kartu Keunggulan dengan ikon custom
- Galeri foto suasana belajar dan kegiatan bimbingan
- Testimoni orang tua dan siswa dalam grid kartu dengan rating bintang
- Form Konsultasi Gratis dengan validasi inline per field tanpa alert browser, mencakup nama, no HP atau WhatsApp, jenjang anak, sekolah asal, mata pelajaran yang ingin dikonsultasikan, dan catatan tambahan
- FAQ accordion dengan ikon plus yang berputar saat item aktif
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
