# Company Profile 01 - Rimba Kitchen & Co.: Restoran & Kafe Modern

Landing page company profile untuk restoran modern Indonesia fiktif dengan konsep bahan segar lokal dan suasana hangat.

**Tagline:** Rasa Asli, Alam Sejati.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Fraunces, Outfit)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Sticky navbar transparan dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan foto latar, badge lokasi, dan stats bar dengan animated counter scroll triggered
- Marquee berjalan menampilkan daftar menu andalan
- Menu Andalan, grid 6 hidangan dengan foto, deskripsi, dan harga
- Galeri suasana restoran (indoor dan outdoor)
- Testimoni pelanggan dengan rating bintang
- FAQ accordion dengan smooth expand dan collapse
- Form reservasi meja dengan validasi inline (tanpa alert browser)
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Footer dengan navigasi cepat
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
