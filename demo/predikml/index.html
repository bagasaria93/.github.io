Cara Kerja PredikML

                

                    

                        
1. Pilih Dataset

                        
Pilih salah satu dari tiga dataset contoh yang mewakili pola penjualan berbeda, mulai dari retail, SaaS, hingga manufaktur.

                    

                    

                        
2. Python Berjalan di Browser

                        
Pyodide memuat interpreter Python beserta NumPy dalam bentuk WebAssembly, sehingga kode Python berjalan langsung di browser tanpa server.

                    

                    

                        
3. Lihat Prediksi

                        
Model regresi linear OLS menghitung R², MAE, dan proyeksi tiga bulan ke depan, lalu hasilnya ditampilkan dalam grafik interaktif.
