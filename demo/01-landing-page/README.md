# Demo 01 - Sinkron: Responsive Landing Page

Platform SaaS manajemen proyek untuk tim remote Indonesia.

**Tagline:** Tim kamu, satu ritme.

---

## Tech Stack

- HTML5, CSS3
- Tailwind CSS (via CDN)
- Vanilla JavaScript

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Sticky navbar dengan backdrop blur on scroll
- Mobile hamburger menu dengan full-screen overlay
- Hero section dengan word swap animated headline
- Product UI mockup interaktif: Kanban board dengan drag-and-drop
- Stats section dengan animated counter scroll-triggered
- Features section dengan 6 feature cards dan hover microinteractions
- Pricing section dengan toggle IDR/USD dan toggle bulanan/tahunan
- Testimonials section (nama dan perusahaan fiktif Indonesia)
- FAQ accordion dengan smooth expand/collapse
- CTA section
- Footer dengan sitemap links
- Scroll progress bar di atas halaman
- Active nav highlight sesuai section yang terlihat
- Toast notification saat klik CTA button
- Scroll-triggered reveal animations
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser. Tidak memerlukan server atau dependensi tambahan.
