# Demo 02 - PesanPro: B2B Company Profile

Platform SMS Masking & Gateway SMS untuk bisnis Indonesia.

**Tagline:** Kirim SMS ke Ribuan Pelanggan dalam Hitungan Detik.

---

## Tech Stack

- HTML5, CSS3
- Tailwind CSS (via CDN)
- Vanilla JavaScript

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Sticky navbar dengan backdrop blur on scroll
- Active nav highlight sesuai section yang terlihat
- Mobile hamburger menu dengan full-screen overlay
- Hero section dengan animated typing text (SMS Masking, OTP Verification, dll)
- SMS mockup preview interaktif dengan staggered fade-in animation
- Trust badges (Terdaftar Kominfo, SSL Secured, Uptime)
- Stats section dengan animated counter scroll-triggered
- Services section dengan 6 layanan cards dan hover microinteractions
- How It Works section (3 langkah: Daftar → Integrasi → Kirim)
- Why Us section dengan delivery rate progress bar dan stats cards
- Pricing section dengan 3 tier (Starter, Business, Enterprise)
- Testimonials section B2B (nama dan perusahaan fiktif Indonesia)
- FAQ accordion dengan smooth expand/collapse
- Leads form lengkap dengan validasi visual, loading state, dan character counter
- Google Maps embed
- WhatsApp floating button dengan pulse animation
- CTA section
- Footer dengan sitemap links
- Scroll progress bar di atas halaman
- Toast notification
- Scroll-triggered reveal animations
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser. Tidak memerlukan server atau dependensi tambahan.
