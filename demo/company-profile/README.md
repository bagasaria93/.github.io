# Demo 02 - ForgeX Gym: Company Profile

Landing page pusat kebugaran premium dengan trainer bersertifikat internasional dan fasilitas modern.

**Tagline:** Forge Your Best Self.

---

## Tech Stack

- HTML5, CSS3
- Tailwind CSS (dikompilasi via CLI, bukan CDN runtime)
- Vanilla JavaScript
- Google Fonts (Oswald, Outfit)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Sticky navbar transparan dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full-screen overlay
- Hero section dengan diagonal accent, background image, dan pattern grid
- Marquee berjalan menampilkan daftar program
- Stats bar dengan animated counter scroll-triggered
- 6 program latihan (Strength, HIIT, Yoga, Muay Thai, Personal Training, Nutrition Coaching)
- Grid trainer dengan foto, sertifikasi, dan pengalaman
- Pricing 3 tier (Starter, Pro, Elite) dengan tier "Pro" yang ditonjolkan
- Testimonial member dengan rating bintang
- FAQ accordion dengan smooth expand/collapse
- Form pendaftaran trial dengan validasi inline (tanpa alert browser)
- Info lokasi dan kontak WhatsApp
- WhatsApp floating button
- CTA section penuh warna
- Footer dengan navigasi cepat
- Scroll-triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser. CSS Tailwind sudah dikompilasi ke `tailwind.min.css` di folder yang sama, tidak memerlukan server atau proses build tambahan untuk menjalankannya.
