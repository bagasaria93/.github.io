# Company Profile 10 - Danamitra Finance: Perusahaan Pembiayaan

Landing page company profile untuk perusahaan pembiayaan (multifinance) fiktif yang melayani kredit motor, mobil, elektronik, dan dana tunai jaminan BPKB.

**Tagline:** Wujudkan Kebutuhan Anda dengan Cicilan yang Ringan.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Plus Jakarta Sans, Inter)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna teal tua dan gold hangat di atas latar mist putih, memberi kesan finansial yang terpercaya sekaligus modern
- Sticky navbar transparan yang berubah menjadi solid dengan backdrop blur saat scroll
- Mobile hamburger menu dengan panel slide dan overlay
- Hero section dengan kalkulator simulasi cicilan interaktif sebagai elemen visual utama, bukan foto, dan baris statistik angka yang animasi saat scroll
- Kalkulator Simulasi Cicilan dengan slider jumlah pinjaman, tombol pilihan tenor 12, 24, 36, dan 48 bulan, serta hasil estimasi cicilan per bulan yang dihitung otomatis secara real time, dilengkapi catatan bahwa angka bersifat estimasi bukan penawaran resmi
- Grid produk pembiayaan (Kredit Motor, Kredit Mobil, Kredit Elektronik, Dana Tunai BPKB) dengan ikon custom dan indikasi cicilan atau plafon
- Bagian Keunggulan dengan foto konsultasi, kartu statistik mengambang, dan daftar keunggulan berikon
- Alur Cara Pengajuan empat langkah bernomor
- Bagian Jaringan Cabang dengan statistik dan grid daftar kota
- Testimoni nasabah dalam kartu dengan rating bintang
- Form Pengajuan dengan panel info berlatar foto, dan validasi inline per field tanpa alert browser, mencakup nama, no HP, jenis pembiayaan, kota domisili, dan estimasi nominal
- FAQ accordion dengan ikon plus yang berputar saat item aktif
- Info kontak kantor pusat, telepon, dan email
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
