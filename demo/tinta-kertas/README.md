# Company Profile 13 - Tinta & Kertas: Percetakan Digital, Offset & Large Format

Landing page company profile untuk percetakan fiktif yang melayani cetak digital, offset, large format banner, kartu nama, stiker, hingga kemasan custom.

**Tagline:** Dari File ke Cetakan, Tanpa Meleset Warna.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Space Grotesk, IBM Plex Mono, Inter)

## Konsep Desain

Desain mengangkat identitas visual proses cetak profesional (registrasi warna, color bar CMYK, proofing, stempel quality control), dibedakan dari demo company profile lain lewat pendekatan tata letak dan tipografi yang berbeda:

- Palet warna netral kertas dan hitam pekat dengan aksen CMYK (cyan, magenta, kuning) dipakai secukupnya sebagai penanda kategori dan detail, bukan warna dominan, supaya tetap terlihat premium
- Tipografi Space Grotesk untuk judul, IBM Plex Mono untuk label dan data teknis, Inter untuk isi
- Elemen registration mark (tanda crop/target khas dunia cetak) sebagai bingkai foto hero, bukan dekorasi acak
- Color bar empat warna CMYK sebagai garis aksen di header dan penanda logo
- Header solid dengan navigasi horizontal dan menu mobile berupa panel slide-in dari kanan, berbeda dari overlay penuh layar maupun dropdown di demo lain
- Kartu layanan bertanda kode kategori berwarna (DG.01, OF.02, dst) mengikuti gaya kode job cetak
- Alur kerja disajikan sebagai garis waktu horizontal dengan garis putus-putus menyerupai garis potong (cutting guide), bukan tabel atau kartu bernomor
- Simulasi paket disajikan bergaya nota atau invoice dengan garis titik-titik dan font monospace
- Testimoni memakai badge stempel bulat "QC OK" menyerupai stempel approval proof cetak, bukan rating bintang atau tag referensi job
- Galeri menampilkan mesin cetak digital, mesin offset, dan meja proofing warna sebagai bukti fasilitas produksi asli, bukan hanya hasil jadi

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Header dengan color bar CMYK dan navigasi sticky
- Menu mobile slide-in panel dari sisi kanan dengan overlay gelap
- Hero dengan foto miring bertumpuk gaya proof cetak, bingkai registration mark, dan panel spesifikasi cetak (mode warna, resolusi, estimasi produksi, area kirim)
- Enam kategori layanan (cetak digital, offset dan large format, kartu nama dan stationery, stiker dan label, kemasan custom, color matching dan proofing) dengan foto asli mesin dan hasil cetak
- Bagian Kenapa Kami dengan foto lantai produksi asli dan daftar keunggulan bernomor
- Alur Kerja lima langkah sebagai garis waktu horizontal interaktif
- Galeri Fasilitas menampilkan mesin large format, mesin offset, meja proofing warna, dan hasil cetak
- Simulasi tiga paket cetak bergaya nota dengan satu paket ditonjolkan sebagai paling laris
- Testimoni klien dengan badge stempel quality control
- FAQ accordion dengan ikon plus yang berubah menjadi minus saat aktif
- Form Konsultasi Pesanan dengan validasi inline per field tanpa alert browser, mencakup nama, instansi, WhatsApp, jenis cetakan, perkiraan jumlah, target selesai, dan catatan
- Info kontak alamat workshop, telepon, email, dan jam operasional
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
