# Demo - TopUpKu: Platform Top Up Game

Platform top up game dengan alur pembelian 5 langkah, simulasi API supplier, dan panel admin untuk memantau transaksi.

**Tagline:** Top Up Cepat, Aman, Terpercaya.

---

## Tech Stack

- HTML5, CSS3
- jQuery
- Chart.js
- Vanilla JavaScript (localStorage sebagai database demo)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Alur pembelian 5 langkah dengan step indicator: Pilih Game, Nominal, ID Player, Pembayaran, Status
- Grid game dan nominal dengan badge "POPULER"
- Verifikasi ID Player dengan simulasi delay dan preview nama akun
- Dukungan server/region untuk game yang memerlukannya
- Berbagai metode pembayaran: E-wallet, Transfer Bank, dan lainnya
- Simulasi proses transaksi dengan log API real-time
- Status transaksi Sukses, Gagal, dan Pending dengan countdown timer
- Panel Admin dengan statistik, grafik revenue 7 hari terakhir, grafik distribusi game, dan riwayat transaksi
- Reset data demo ke kondisi awal

## Cara Menjalankan

Buka file `index.html` langsung di browser. Tidak memerlukan server atau proses build tambahan untuk menjalankannya.
