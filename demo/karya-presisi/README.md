# Company Profile 09 - Karya Presisi: Precision Contract Manufacturing

Landing page company profile untuk perusahaan contract manufacturing fiktif yang melayani CNC machining, fabrikasi dan pengelasan logam, plastic injection molding, hingga assembly line untuk perusahaan industri di kawasan Bekasi, Cikarang, dan Karawang.

**Tagline:** Mitra Manufaktur Presisi untuk Kebutuhan Produksi Industri Anda.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Saira Condensed, IBM Plex Sans, IBM Plex Mono)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna charcoal dan orange industrial di atas latar abu terang, dipadukan dengan pola grid teknikal pada bagian gelap untuk kesan presisi dan engineering
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan panel slide dan overlay
- Hero section dengan baris statistik angka yang animasi saat scroll dan badge sertifikasi mengambang
- Grid Kapabilitas Produksi untuk CNC machining, fabrikasi dan pengelasan logam, plastic injection molding, dan assembly line
- Lini Produksi interaktif berupa alur kerja bernomor lima tahap (bahan baku, processing, quality control, assembly, pengiriman) yang bisa diklik untuk menampilkan foto dan penjelasan tiap tahap, dengan indikator progres pada garis penghubung
- Grid Industri yang Dilayani lintas sektor otomotif, elektronik, alat berat, consumer goods, furnitur, dan energi
- Bagian Sertifikasi menampilkan badge ISO 9001:2015 dan sistem manajemen K3
- Galeri foto fasilitas produksi dengan layout grid asimetris
- Testimoni B2B dari beberapa tim procurement dan operasional klien
- Form Request for Quotation (RFQ) dengan validasi inline per field tanpa alert browser, mencakup nama perusahaan, PIC, email, no HP, jenis kebutuhan, estimasi volume, dan catatan tambahan
- FAQ accordion dengan ikon plus yang berputar saat item aktif
- Info kontak, alamat fasilitas, dan jam operasional
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
