# Company Profile 02 - Studio Embun: Beauty and Skincare Studio

Landing page company profile untuk studio kecantikan dan perawatan kulit fiktif, meliputi facial dan skincare, makeup dan styling, brow dan lash, hingga body dan spa.

**Tagline:** Kecantikan yang Merawat, Bukan Menutupi.

---

## Tech Stack

- HTML5, CSS3 (hand written, self contained, tanpa dependency framework CSS eksternal)
- Vanilla JavaScript
- Google Fonts (Playfair Display, DM Sans)

## Fitur

- Fully responsive (mobile, tablet, desktop)
- Palet warna wine dan gold di atas latar greige hangat, berbeda dari demo lain agar terasa seperti studio kecantikan premium
- Sticky navbar dengan backdrop blur saat scroll
- Mobile hamburger menu dengan full screen overlay
- Hero section dengan foto blob berbentuk organik dan garis bawah gold hand drawn pada kata penekanan
- Baris kredensial tipis menampilkan angka klien, terapis, treatment signature, dan keamanan produk
- Kategori Layanan dengan tab interaktif yang mengganti foto dan label suasana sesuai kategori dipilih
- Treatment Unggulan dalam list baris horizontal lengkap dengan durasi dan harga
- Paket dan Membership tiga kolom dengan kartu unggulan bergaris tepi gold dan label sudut
- Cerita Kami dengan foto berbingkai offset gold, kutipan, dan tiga pilar nilai brand dalam baris horizontal
- Galeri suasana studio dalam grid mosaic dengan label muncul saat hover
- Testimoni pelanggan dalam marquee yang bergulir otomatis dan berhenti saat kursor diarahkan
- FAQ accordion dengan ikon chevron melingkar dan latar highlight pada item aktif
- Form kontak dengan validasi inline (tanpa alert browser)
- Info lokasi, jam operasional, dan kontak WhatsApp
- WhatsApp floating button
- Scroll triggered reveal animation via IntersectionObserver
- Smooth scroll navigation

## Cara Menjalankan

Buka file `index.html` langsung di browser, tidak perlu server atau proses build tambahan.
